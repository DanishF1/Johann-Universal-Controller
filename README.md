## About The Project

**Johann Universal Controller** is the official mobile command center built to pilot the Johann Drone. Designed with a custom immersive, high-contrast dark mode interface, it ensures optimal visibility and precision control during flight operations. The application leverages Bluetooth Low Energy (BLE) to establish a fast and reliable connection between the smartphone and the drone's microcontroller system.

### Specifications & Features

* **Platform:** Android
* **Core Languages:** Kotlin (Logic & Communication), XML (UI/UX Design)
* **Communication Protocol:** Bluetooth Low Energy (BLE)
* **Flight Controls:** * State-based switches for **Ascend**, **Hover**, and **Descend** maneuvers.
    * Precision linear slider for **Altitude** adjustments.
* **User Interface:** * Custom-built Landscape orientation using rotated constraints for an uninterrupted immersive experience.
    * Full-screen mode (Status Bar and Navigation Bar hidden) to prevent accidental exits during flight.
    * High-contrast color palette (Pure Black, Gray, and White) designed for outdoor visibility.
* **Upcoming Features:** Video Recording integration (TBA).
